# ⚡ Comandos y Prompts para Agentes IA (`.agents/commands/`)

Esta carpeta contiene plantillas de prompts y runbooks de comandos listos para ser utilizados por agentes IA (Gemini, Claude, Antigravity) o por desarrolladores para acelerar flujos de trabajo repetitivos.

## Catálogo de Comandos Disponibles

| Comando / Archivo | Propósito | Cuándo usarlo |
|---|---|---|
| [`new-feature.md`](./new-feature.md) | Desarrollo de nueva funcionalidad | Crear vistas, componentes, servicios y lógica end-to-end |
| [`create-migration.md`](./create-migration.md) | Creación de migraciones SQL y RPCs | Crear tablas, RLS, índices o funciones en Supabase |
| [`debug-issue.md`](./debug-issue.md) | Diagnóstico y depuración | Investigar errores en producción, RLS, sync de órdenes o pagos |
| [`validate-all.md`](./validate-all.md) | Validación total estricta (TypeScript + ESLint + Tests + Build) | Protocolo obligatorio antes de entregar cualquier cambio |
| [`verify-and-build.md`](./verify-and-build.md) | Verificación y CI local | Ejecutar linters, chequear TypeScript y compilar bundle |
| [`test-offline-sync.md`](./test-offline-sync.md) | Pruebas del modo Offline | Simular pérdida de conexión, encolado de órdenes y re-sincronización |
